THE GAME (target: genuinely fun and good-looking, not a bare prototype)
A live geo-guessing battle royale played from MAP SHAPES ALONE (no photos). Each clue is a real location, shown as a framed map snippet (e.g. a ~150–400 km window) that reveals in 4 timed stages:
 1) coastline / land outline (and lakes)
 2) + rivers
 3) + roads (and maybe railways / urban areas)
 4) + place names in the LOCAL SCRIPT (e.g. Cyrillic, Arabic, Devanagari, Thai, Chinese), with Latin names never shown.
Players drop a pin on a world map (pan/zoom, mobile pinch) and can LOCK IN anytime. Score = distance-based (e.g. 5000*exp(-d/2000km) style) times a stage multiplier (lock-in during stage 1 = x2.0, stage 2 = x1.6, stage 3 = x1.3, stage 4 = x1.0). A round lasts ~30–40 s total. After each round: animated reveal (line from guess to truth, distance, points), standings. After rounds 2–6, the bottom 20% (by total score) are eliminated and become spectators. 7 rounds max, or last few standing win. Then a winner screen and an instant "play again" in the same room.

DATA (free + licensed): Use Natural Earth (public domain) vector data, downloaded with curl from https://naciscdn.org/naturalearth/ (e.g. 10m_physical/ne_10m_land.zip, ne_10m_coastline, ne_10m_lakes, ne_10m_rivers_lake_centerlines, 10m_cultural/ne_10m_roads.zip, ne_10m_railroads, ne_10m_urban_areas, ne_10m_populated_places with name_xx fields such as name_ru, name_ar, name_zh, name_ja, name_ko, name_hi, name_el, name_he, name_fa, name_uk, name_th, name_bn...). If a URL fails, try https://www.naturalearthdata.com/http//www.naturalearthdata.com/download/10m/... mirrors. Write an offline build script (Node or Python; you may pip install --user shapely/pyshp or npm install shapefile/mapshaper/topojson) that pre-builds clue packs: pick ~150+ interesting, recognizable-but-not-trivial locations worldwide (balanced across continents; include distinct coastlines, river deltas, islands, inland road-hub cities), clip each layer to the window, simplify, and save compact JSON (or TopoJSON) per clue, plus a low-res world basemap for the guessing map. Choose the local-script language per location by country (fallback to the closest available name field; if the local name is Latin script, pick stage-4 labels anyway but mark that stage as less informative, or prefer locations with non-Latin scripts for variety).
